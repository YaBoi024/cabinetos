# What the console's RomM client sends to RomM and reads from its answers (#729).
#
# One block a call, held by ci/check-romm-api.py to RomM's own description of its
# API (ci/romm-api.json) and to the client's code. A call is METHOD /path, its
# path parameters in braces; under it, indented:
#
#   query name name              settings it puts in the address
#   send path kind               a field it sends in the body (a part of an upload)
#   read path kind               a field it reads from a good answer
#   undeclared name: reason      a name RomM's description does not spell out
#
# A path names a field inside a field: `a.b`, `a[].b` (a list's entries), `a.{}.b`
# (a map's values). Kinds are text, number, yesno, list, object and any. Only
# what the client really reads or sends is here; RomM may answer more. A name
# the code spells that is not here fails the check, so a new field a call reads
# is added in the same pull request. ci/check-romm-api.py's header says what it
# checks and what it does not.
