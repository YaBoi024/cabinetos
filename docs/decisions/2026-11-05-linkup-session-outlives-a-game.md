# A LinkUp session ends when the friend leaves, not when a game does

- **Decided:** A friend leaving ends the session, by Leave, the minute running out, or their console powering off: "Alex left". The host's game carries on as a normal game with other controllers working, and player two stays plugged in and idle. There is no rejoining after a restart. Quitting a game keeps the session: the friend sees "Waiting for Alex", the host lands on the game list with "Linked up with Alex" on top, and the next game starts on both with no new invite. B asks "End the session with Alex?", and about five minutes with nothing picked ends it. The host ending it or powering off ends it for the friend. A crash counts as quitting.
- **Date:** 2026-11-05
- **Why:** One rule for every game: an unplugged controller stops some games, and idle stops none. A second session is one invite away. Two friends often play several games, and asking again each time adds nothing.
- **Numbers:** #654, "LinkUp: play a game with a friend on another CabinetOS console over the internet"; PR #666, "LinkUp: the console's side, step 3 of #654".
- **Replaces:** none.
