# No option on a main screen for a few players

- **Decided:** An option, button or setting that only a few players would use never goes on a main screen: Home, a system's grid or a game's page. If it is worth having at all, it goes in a separate menu; often the answer is no option.
- **Date:** 2026-10-13
- **Why:** Home, the grids and the game's page are judged and polished on the TV, and every added row or button costs every player for the benefit of a few. It came up with a version button proposed for the game's page (#383): game versions ended with no menu at all, each version keeping its own tile with RomM's tags in the heading. The Arcade tile has no setting to turn it off and no filter for the same reason.
- **Numbers:** #383, "Same-name games: show RomM's tags in the heading", and docs/PROJECT.md question 48; #611, "Proposal, not decided: one Arcade tile for every arcade folder".
- **Replaces:** none.
