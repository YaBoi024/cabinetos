# Others may try the portable install, as an alpha

- **Decided:** Anyone may try the portable install from its wiki page, `docs/wiki/portable.md`, which calls it an alpha and lists what has and has not been tried. It does not wait for a PC with BitLocker, Secure Boot on real firmware or a faster drive to be tried here first.
- **Date:** 2026-11-04
- **Why:** At first nobody else was to try it, because a portable promises to leave the PC alone, and breaking that promise harms someone else's PC. That changed once the file had run on a real PC with Windows and Windows still started: the rest needs PCs this project does not have, a faster drive is a while away, and the whole project is an alpha. So what is untried is said at the top of the page, and the person trying it decides. The steps have them save their BitLocker recovery key first.
- **Numbers:** PR #653, "Portable install, step 3: the disk image and its boot check"; PR #656, the sound fix that carried it. PR #657, "The wiki says how to run CabinetOS from a USB drive".
- **Replaces:** none.
