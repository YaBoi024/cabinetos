# No emulator reaches the network

- **Decided:** One block keeps every emulator off the network, the ones added later included. Inside the console's program (every libretro core, and PS2), the program's own `socket`, name lookups and `pthread_create`, exported so every library reaches them first, refuse an emulator's internet socket and every name lookup it asks for, and log each once a game (`frontend/src/netblock.cpp`); the console's own requests are untouched. An emulator run as a program starts with no network: the image's under `bwrap --unshare-net` with systemd-resolved's folder hidden, the Flatpaks with `flatpak run --unshare=network` (`frontend/src/standalone.cpp`, `standalone_xemu.cpp`). Nothing else is touched: updates, Tailscale, Sunshine, Flathub installs, Steam and Remote Play are never started as emulators.
- **Date:** 2026-10-26 (approved by MMagTech)
- **Why:** The console connects only to fixed places the code chooses (CONTRIBUTING.md, "The rules"), and an emulator reaches wherever its game does. Dolphin asked Nintendo's old servers for Wii games, the Wii Shop's answered, and one name still resolves to an address that never answers, so leaving Mario Kart Wii waited out curl's 60 s (2026-10-22). A setting or a patch per emulator is what the 3DS had, and every new emulator would need its own. Inside the program, who asked is told by the code that called: the first frame that is the console or an emulator library decides, because Dolphin and PCSX2 use the same libcurl the console uses for RomM; a thread an emulator starts is the emulator's for its whole life, which catches curl's lookup threads. Outside it, systemd-resolved still answers a lookup over its Unix socket in a sandbox with no network, which is why its folder is hidden. Weighed and not taken: a console-wide firewall allow-list (a root service fed the addresses of RomM, GitHub, RetroAchievements, Flathub, Tailscale and Steam, where one mistake cuts the console off its server); every core moved into a program of its own so one sandbox covers both halves (a rewrite of the core host); a setting or patch per emulator.
- **Numbers:** #557, "No emulator reaches the internet: one block for all of them (Wii's slow Mario Kart exit, 3DS)", its research comment of 2026-10-26; #595, "No emulator reaches the internet: one block for all of them (#557)"; #537, "Azahar patch: games get no network (until Azahar has an option)".
- **Replaces:** the patch to Azahar that kept 3DS games off the network ([3ds-games-get-no-network](2026-10-20-3ds-games-get-no-network.md), #537), removed from `cores/build-core.sh`. Eden's airplane mode and every emulator's update-check setting stay: they are settings, not patches.
