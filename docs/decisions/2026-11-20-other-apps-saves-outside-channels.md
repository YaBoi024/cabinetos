# Another app's save outside channels is not copied into one

- **Decided:** When a game starts from another app's save that is in no channel, the console leaves that save on RomM as it is and copies nothing; the console's own next save goes into its channel as always.
- **Date:** 2026-11-20
- **Why:** An app that saves outside channels is that app's to move onto them. The save stays safe on RomM, so a copy would only duplicate it.
- **Numbers:** #346 "Move saves to RomM's save channels (Sigil)"; #722 "Save channels: the console's saves move to RomM's channels (#346, steps 2 to 11)".
- **Replaces:** none.
