# Tailscale has its own switch, in Network, apart from Remote Play

- **Decided:** Tailscale is its own switch, the row after Wi-Fi in Settings, Network, and runs whenever it is on; turning Remote Play on or off no longer starts or stops it, and neither does a LinkUp session. Remote Play stays in Streaming. With a PIN set, Disconnect now asks for it, as turning on, Connect, Sign in again and Log out already did. The row stays greyed while a device streams. The first start after the update saves Tailscale off on a console that had it on with Remote Play off, whose row read Off, and keeps its sign-in; the boot script starts tailscaled by the same rule and never writes the settings. MagicDNS and other devices' routes stay off, and the firewall still lets in only Sunshine's ports. A RomM server reached through Tailscale is given by its Tailscale address, as the console's one server address.
- **Date:** 2026-11-15
- **Why:** Tailscale is network plumbing, set up by whoever installs the console; a player cares only about Remote Play's one switch. A player asked to reach RomM at its Tailscale address without Sunshine running, and a console whose server address was a Tailscale address lost its server whenever Remote Play was turned off. Disconnect can now cut the console off from its server, so it is guarded like Log out. The step after the update keeps an update from turning on what a player saw as off. MagicDNS stays off because a tailnet set to override local DNS would send every lookup the console makes through the tailnet. There is still one server address, never a second one for away from home.
- **Numbers:** none; a player's request on Discord, agreed with MMagTech on 2026-11-15. Moved from docs/PROJECT.md, question 39, "Remote Play (Sunshine), issue #286", its Tailscale paragraph.
