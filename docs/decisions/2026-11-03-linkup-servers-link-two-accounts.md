# Linked LinkUp servers connect the two accounts picked and nobody else

- **Decided:** Two owners who each run a server link them with a code made on the admin pages, and each picks an account; those two accounts are now friends. Everyone else on each server stays on that server only, and there is no chain to a third. More pairs can be added to a link the same way, either owner can remove a pair or the whole link, and the consoles change nothing. Someone who runs no server pairs with someone else's instead.
- **Date:** 2026-11-03
- **Why:** Two friends who each run a server can play together while each still hosts their own people. The costs: server-to-server code in the container, two servers of different ages have to work together, someone else on your server cannot play with your linked friend, and if your server is off you reach nobody.
- **Numbers:** #654, "LinkUp: play a game with a friend on another CabinetOS console over the internet".
- **Replaces:** the ideas, earlier the same day, that everyone on two linked servers sees each other, and then that each person has a switch for sharing across a link.
