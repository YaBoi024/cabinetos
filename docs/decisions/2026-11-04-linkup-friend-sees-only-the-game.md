# A LinkUp friend sees only the game, and "Waiting for" the host otherwise

- **Decided:** Whenever the host's console shows anything but the game (a download, the loading screen, the pause menu, any other screen, a PIN being typed), no picture or sound is sent, and the friend's console shows "Waiting for Alex". The friend's presses do not reach the host's console during that time, and Leave still works. The game comes back by itself when the host does.
- **Date:** 2026-11-04
- **Why:** The capture takes the whole screen, so without this the friend would watch the host's menus and PIN entry and hear the menu sounds. One screen covers every wait, and a wait costs no data on either connection or the relay.
- **Numbers:** #654, "LinkUp: play a game with a friend on another CabinetOS console over the internet"; PR #666, "LinkUp: the console's side, step 3 of #654".
- **Replaces:** none.
