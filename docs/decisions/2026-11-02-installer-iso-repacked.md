# The installer ISO is repacked after the builder

- **Decided:** Every installer ISO bootc-image-builder makes is repacked in `build-disk.yml` by `ci/brand-installer-iso.sh`, before it is uploaded or published. The repack changes the boot menu (one entry, Install CabinetOS, a picture of the console's start screen under UEFI, a quiet start) and adds a product image the installer lays over itself (CabinetOS's colours and logo, the title without Fedora's version, Network & Host Name hidden). Nothing the builder made is unpacked or rebuilt. A splash while the installer loads is left out: Plymouth has only text themes in the installer, so a picture would mean rebuilding its initrd.
- **Date:** 2026-11-02
- **Why:** MMagTech wanted the installer's screens to look like CabinetOS rather than Fedora, judged from VM screenshots. The builder has no setting for any of it (#284). The other way, the successor builder's `bootc-installer` ISO type, is a different installer model and a much bigger piece of work. A repack keeps the builder's ISO byte for byte and changes only what the installer is built to take from its media: the boot menu and `images/product.img`.
