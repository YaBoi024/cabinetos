# Wi-Fi scans only on a weak signal, and Wi-Fi power saving off

- **Decided:** After every Wi-Fi connect, a NetworkManager dispatcher script gives wpa_supplicant ChromeOS's background scan rule for one access point, `simple:360:-70:86400`, in place of NetworkManager's: no scan while the signal is -70 dBm or better, one at once when it drops below, then one every 6 minutes while it stays below. Wi-Fi power saving is off on every console (`wifi.powersave = 2`). Both for every console, always, with no setting. The script is `system_files/usr/lib/NetworkManager/dispatcher.d/50-cabinetos-wifi-scans`, the setting `system_files/usr/lib/NetworkManager/conf.d/50-cabinetos-wifi.conf`, and `build_files/wifi-scan-rule.sh` stops the build if NetworkManager's rules or its Wi-Fi backend change, or it stops reading the setting.
- **Date:** 2026-11-08
- **Why:** NetworkManager gives a network seen from two access points or more (a mesh, an extender, one router's two bands) `simple:30:-65:300`: a scan of every channel every 300 seconds. On the reference console's MediaTek card a scan is 98 channels in 9.6 s, leaving the channel for about 45 ms in every 220, so a game streamed over Wi-Fi (LinkUp, Remote Play, Steam's) stuttered for ten seconds every five minutes. Its other rule, `simple:30:-70:86400`, scans every 40 seconds below -70 dBm (measured with the threshold set above the console's signal). NetworkManager 1.56 has no setting for either (its issue #1077 was closed; merge request !2593, open, would add one). ChromeOS's one-access-point rule never scans more than either of NetworkManager's, at any signal, and still scans at once when the signal drops, so a console with a better access point near still moves to it. wpa_supplicant 2.11 takes a new rule over D-Bus while connected, with no reconnect. With power saving on, a game's sound reached a Wi-Fi friend up to 64 ms late, past the friend's 40 ms queue, so the queue grew; off, 31 ms at most (one six-minute run each, host on a cable, and the ping log in the same minutes agreed). A console is on mains power.
- **Numbers:** #654, "LinkUp: play a game with a friend on another CabinetOS console over the internet"; PR #666, "LinkUp: the console's side, step 3 of #654".
- **Replaces:** none.
