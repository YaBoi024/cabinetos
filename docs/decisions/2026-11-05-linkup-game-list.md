# LinkUp lists only games a friend can play, one-player games included

- **Decided:** While inviting, the game list leaves out Wii games that need a Remote, light-gun games, handheld systems and Steam, and a system left with none has no tile. One-player games stay listed: the stream runs, the game ignores player two, and the friend watches or you pick another.
- **Date:** 2026-11-05
- **Why:** A friend's virtual controller cannot carry a Remote's motion or pointer, or hold a gun, and Steam's games are Steam's: nothing of Steam runs while the console does. One-player games stay because nothing breaks; RomM holds game modes and a player count, but the count says 1 for Contra III and Burnout 3, and a game tagged wrong would vanish with nobody knowing why.
- **Numbers:** #654, "LinkUp: play a game with a friend on another CabinetOS console over the internet"; PR #666, "LinkUp: the console's side, step 3 of #654".
- **Replaces:** Wii Remote games shown greyed, as Remote Play shows them.
