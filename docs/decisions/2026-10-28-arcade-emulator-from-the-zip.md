# An arcade game's emulator comes from the files in its zip

- **Decided:** The console picks an arcade game's emulator from its zip. The zip's name is the set's name, and its files (names, sizes and CRCs) must be the ones that emulator's own list gives for the set, leaving out BIOS options, files with no dump and optional files. A set with a disc also needs its CHD, with the SHA1 the list gives. Emulators are tried in a fixed order, Flycast, FinalBurn Neo, MAME 2003-Plus, sm2-emu, Supermodel, MAME 0.289, and one whose list marks the game not working is skipped. A folder's name no longer chooses. A game no emulator here plays, or one an emulator's own list marks as made for anything but a controller (a touchscreen, a mahjong or hanafuda panel, a gambling, medal or electromechanical machine), is greyed *Not supported*, and a light-gun game *Needs a light gun* until #575. Every arcade folder is one Library tile, Arcade ([one-arcade-tile](2026-10-29-one-arcade-tile.md)). Neo Geo games run as the arcade board (MVS). Sets may be zip or 7z; MAME 2003-Plus, which cannot open a 7z, is skipped for one.
- **Date:** 2026-10-28
- **Why:** A folder's name cannot say which sets are inside it: Batocera's `mame` folder means MAME 2003-Plus and ES-DE's means current MAME. Every emulator finds a game by its zip's name, so the name finds the set and the files confirm it; files alone picked the wrong game in the audit of 2026-10-27, and this rule picked the right emulator for all 740 zips in it. The same game gets the same emulator on every console, whoever plays it. MAME 2003-Plus comes before MAME 0.289 because it never moves, so a MAME update cannot change the games both run; sm2-emu and Supermodel come before MAME 0.289 because they are made for Model 2 and Model 3, which MAME mostly marks not working. MMagTech, 2026-10-28: this is a console, for games played with a controller and later a light gun; for every library, not only his, and what the lists do not mark plays, so a few are missed.
- **Numbers:** #575, "Sinden light guns: plug in and play gun games"; the arcade planning of 2026-10-27 and 2026-10-28, no issue.
- **Replaces:** for arcade, #310, "Arcade games in any RomM arcade folder show up, not only in folders named exactly FBNEO or MAME2003", where a folder named after an emulator chose it.
