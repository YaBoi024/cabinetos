# Game events go to one app at home, which does the rest

- **Decided:** The console sends what is happening in a game (started, paused, resumed, ended, an achievement, a set completed, and a test) as JSON to one address the owner types in Settings, System, Game events, and that app (n8n, Home Assistant, Node-RED) decides what happens next: lights, Discord, a phone. It is console-wide and off to start, and Turn off keeps the address, so turning it back on needs no typing; it must be a private, local or Tailscale address, checked every time it sends, after a knock with the test message on every network the console joins. No Discord built in, no switch per message, no QR code. A LinkUp friend's console sends its own started and ended to its own address; nothing about one console's setup crosses LinkUp. Every game message says whether it is a LinkUp game and which side the console is on, hosting or joined, and none names the other person.
- **Date:** 2026-11-15
- **Why:** A post to Discord is a notification like a text, which needs nothing from the console. What only the console can do is say what is happening in the game, so the room can react to it, and that needs one message to an app at home. Each Discord, Telegram or Home Assistant feature built in would be the console managing a service the owner already has an app for. Switches per message would be settings for the few: the app picks what it uses. A QR code would need a web page on the console, and nothing about this needs the console to listen. Home addresses only, and the knock, keep a friend's network from hearing anything, since a private address exists on every network. A game with a friend is a different event in the room, and only the console knows a game is one, so it says so; who the friend is belongs to the friend, so their name never goes to someone else's app or channel (MMagTech's call during the real run, 2026-11-15). Turn off keeps the address because an owner turns it off for a while (guests, an evening without the lights) and back on: built first with the address as the switch, turning it back on meant typing the whole address again with a controller (MMagTech's call on 2026-11-15, before #717 merged).
- **Numbers:** issue #716, "Game events: tell an app at home what is happening in a game", settled with MMagTech on 2026-11-15; PR #717, "Game events: tell an app at home what is happening in a game (#716)", which builds it.
