# A direct LinkUp game shows each console the other's internet address

- **Decided:** Everything is encrypted, every message and not only the stream. A direct game shows each console the other's internet address, and the wiki says so plainly. An invite's game name is readable only by the two consoles, so the server carries it and never learns what anyone plays.
- **Date:** 2026-11-05
- **Why:** WebRTC encrypts by itself, and a direct connection needs the address. That is one more reason LinkUp is only for people an owner chose.
- **Numbers:** #654, "LinkUp: play a game with a friend on another CabinetOS console over the internet".
- **Replaces:** none.
