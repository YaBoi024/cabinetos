# RomM converts saves; the console converts only Switch's, with Sigil

- **Decided:** A save made in another app is converted by RomM, through the Sigil RomM builds in: for every system but Switch, the console asks RomM for it in its own form and converts nothing itself. RomM converts a Switch save only when it knows the game's title ID, and it reads none from an encrypted dump. So for Switch the console carries Sigil: it reads the game's ID with the player's keys and converts that game's saves on the console itself. The console pins Sigil whole, as it pins an emulator, and calls only its Switch parts. The console never writes a title ID, or anything else about a game, to RomM, whoever is signed in. That Switch step comes after step 11 of #346.
- **Date:** 2026-11-20
- **Why:** RomM is the source of truth and of management, and its intent is to do as much as it can. Sigil's maintainer confirmed that a client relying on RomM's conversion is fine, that for Switch a client needs its own solution or another app giving RomM the ID, and that Sigil is the same on either side. RomM keeps players' Switch keys off the server on purpose (rommapp/romm 1055fcff8). Giving RomM an ID needs an admin or editor account. On a family console that would mean lending one person's account to another person's play, and the console never asks to change the library. Dumps that carry a ticket get their ID from RomM's own scan once Sigil reads tickets, which helps every other app with nothing from the console.
- **Numbers:** #346, "Move saves to RomM's save channels (Sigil)"; PR #722, "Save channels: the console's saves move to RomM's channels (#346, steps 2 to 11)"; rommapp/romm#3925, "feat: add binary title ID and save ID extraction during scan"; rommapp/argosy-sigil#30, "switch: read the title id from a dump's ticket when no keys are given".
- **Replaces:** none.
