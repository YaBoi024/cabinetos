# PS3: filtering as the game asked, and small buffers unscaled

- **Decided:** On PlayStation 3, anisotropic filtering is whatever each game asked for (RPCS3's Auto, its default), not the 16x the console forces on every other system, and drawing buffers up to 320 pixels on their longer side stay at the game's own size at every picture level (RPCS3's resolution scale threshold, 16 as it ships). The main 720p picture still scales as the level says.
- **Date:** 2026-11-06
- **Why:** RPCS3's override replaces the filtering a game chose on every texture, including the ones a game reads as data, and Unreal Engine 3 games then draw red noise over the whole picture in play while their menus and cutscenes stay right: Lollipop Chainsaw and Batman: Arkham City on the A9. RPCS3's own pages for both games say to leave the filter on Auto and, when upscaling, to raise the threshold (256 and 320), which fixes red in the shadows. Measured on the A9 the same day, Lollipop Chainsaw at 150%: 100% with the filter still forced changed nothing; the filter on Auto cleared the street and left red in the shadows; the threshold at 256 cleared those. The 16x rule was kept on 2026-10-04 because it costs nothing in speed, so leaving it off costs nothing either, and a game that chose 16x itself keeps it. In RPCS3's per-game list, 96 of 2,294 games need the forced filter off and none need it on. 320 is the larger of the two pages' values; no 720p game draws its main picture that small, so the upscale is untouched.
- **Numbers:** PR #NNN, "PS3: filtering as the game asked, and small buffers unscaled".
- **Replaces:** for PS3 only, the "anisotropic 16x wherever it exists" line of the picture-quality decision of 2026-10-02 (docs/PROJECT.md, #63 phase 1, "what the dial moves"). Every other system keeps 16x.
