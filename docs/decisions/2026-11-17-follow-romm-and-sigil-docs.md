# The console follows RomM's and Sigil's documentation

- **Decided:** For every save that leaves or reaches the console, the console follows RomM's documentation and Sigil's (RomM's save library), and where RomM's documentation says nothing yet, RomM's behaviour. Other apps, such as Argosy and Ludo, are only tested against, never followed. When a save fails between the console and another app, the console's side is checked first; if the console follows the documentation, the fault is taken to be the other app's. A gap in Sigil is closed in Sigil, by pull request, not worked around on the console.
- **Date:** 2026-11-17
- **Why:** RomM is the source of truth for its own data. Other apps differ from one another and change on their own, so following one would tie the console to its choices and its mistakes. A fix made in Sigil reaches every app that uses RomM, not only the console. It covers more than save channels, so it is a file of its own.
- **Numbers:** #346, "Move saves to RomM's save channels (Sigil)"; PR #722, "Save channels: the console's saves move to RomM's channels (#346, steps 2 to 11)"; the gaps closed in Sigil: rommapp/argosy-sigil#22, "nds: convert saves between melonDS's raw file and DeSmuME's .dsv"; #23, "genesis: sync Mega Drive, 32X, Master System and Game Gear saves between genesis_plus_gx and picodrive"; #24, "gba: convert saves between mGBA, gpSP, VBA Next and standalone mGBA"; #25, "xbox360: collect and restore Xenia saves per profile"; #26, "xbox: collect and restore a game's saves on xemu's hard-disk image"; #27, "sync: an optional callback to write part of a file, used for the Xbox drive image".
- **Replaces:** none.
