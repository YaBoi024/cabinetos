# The wiki's side list has five groups, one rule each

- **Decided:** the wiki's side list (`docs/_data/wiki.yml`) has five groups, each with one rule for what goes in it: Set it up (what a new owner does once, in order), Playing (what everyone uses from day to day), Systems (one kind of game), Settings (what is changed once and left) and Help (for looking things up). The Settings group does not copy the console's Settings screen.
- **Date:** 2026-10-29 (decided by MMagTech)
- **Why:** the old groups each followed a different rule (steps, things you do, half the console's menu, and the rest), so a page that fitted none, such as Arcade, went to Reference with the leftovers. With one rule a group, every new page has one place. Weighed and not taken: copying the console's Settings screen, which either loses the Set it up reading order or leaves half a copy; keeping the old groups, which worked, for a modest gain.
- **Numbers:** #612 (The wiki's side list in five groups, and its sound section).
- **Replaces:** none.
