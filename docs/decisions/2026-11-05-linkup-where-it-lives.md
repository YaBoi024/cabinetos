# LinkUp has a screen in the top bar and rows in Streaming, and shows only its switch while off

- **Decided:** Once paired, LinkUp has its own screen in the top bar: Home, Library, Search, LinkUp, Settings. In Settings it shares the Streaming section with Remote Play: Remote Play, Paired devices, Tailscale, LinkUp, Server. Server's panel holds Add a server or Change server, Run your own and Leave. LinkUp is off on every new console, and while it is off the Server row is hidden and the top bar has no LinkUp: a feature that is off shows only its switch.
- **Date:** 2026-11-05
- **Why:** Main screens carry only what every player uses ([no-ui-for-the-few](2026-10-13-no-ui-for-the-few.md)), a feature that is off shows only its switch, and one section keeps the side list at eight.
- **Numbers:** #654, "LinkUp: play a game with a friend on another CabinetOS console over the internet"; PR #666, "LinkUp: the console's side, step 3 of #654".
- **Replaces:** none.
