# The console needs the RomM the wiki names, or newer

- **Decided:** CabinetOS needs the RomM version the wiki names, or newer, and is not built or tested for older ones. A console update that needs a newer RomM than the server has is held back: System update says "Needs RomM 5.5 or newer." and Download is greyed out until the server is updated. The line says what is needed, not which version the server has. A console that cannot tell which RomM its server runs (it has never heard its version, or the server reports "development") holds the update back too, since a later update may need a newer RomM and the console cannot know it has one. A release that needs a newer RomM goes out when it is ready, not when that RomM has a stable version: save channels, which need RomM 5.5, go first to the testing channel for people running RomM 5.5's alpha, and to every console after their feedback.
- **Date:** 2026-11-17
- **Why:** one person keeps the project, so it follows one RomM, and a player who wants what a new version brings updates the server first. Keeping old and new RomM working side by side is work the project cannot keep up. No other app does this (Argosy keeps the old way working on older servers), so it is the project's own choice, not RomM's. Accepted downside: a console whose server is on an older RomM gets no console update of any kind until the server is updated. What the hold cannot catch (a fresh install on an old server, a server put back to an older version, a console that skipped the release that brought the hold) is caught by the console itself: on a RomM too old for it, saves stay on the console and go up by themselves once RomM is updated. Since the hold keeps a console on an older RomM as it is, a release has no reason to wait for RomM's stable version.
- **Numbers:** #346, "Move saves to RomM's save channels (Sigil)"; PR #721, "System update holds back an update the server's RomM is too old for (#346, step 1)"; PR #722, "Save channels: the console's saves move to RomM's channels (#346, steps 2 to 11)".
- **Replaces:** decision 6 of the save channels decisions posted on #346 on 2026-11-15, which let the download go ahead after a warning; and the decision of 2026-10-12 on #346 to keep the old save model until save channels reach a stable RomM release.
