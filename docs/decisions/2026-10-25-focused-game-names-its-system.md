# The focused game's line names its system where the heading does not

- **Decided:** The line beside a heading that names the focused game shows its system after the name, as Home does ("Altered Beast · Sega Genesis"), on Home's shelves, in a collection's grid and in Search. A system's own grid shows the name alone. Wherever it shows, the name is what gets shortened when the line does not fit.
- **Date:** 2026-10-25
- **Why:** Those lists mix systems under a heading that names none, and the same name on two systems is common: the reference library holds an "Altered Beast" for Genesis and one for Game & Watch. A system's grid already says which system in its heading, and saying it twice on every game adds nothing.
- **Numbers:** #579, "A collection's game list does not say which system the focused game is for".
- **Replaces:** none.
