# A console has one LinkUp server, and friends belong to an account on it

- **Decided:** A console has one LinkUp server, added once by the admin and shared by everyone on that console; changing it asks for the PIN. A friend belongs to an account (one RomM account on one console) and lives on the server: your friends show when you are signed in, a child sees only their own, and an account shows as Online only while it is signed in on a console that is on. Only a server's owner makes friends, on the People list. A friend appears by their RomM username, and two with the same name add their server's name. A console removed from a server is told so on LinkUp's screen; a friend removed from an account just leaves that account's list.
- **Date:** 2026-11-03
- **Why:** All the setup stays with the admin, and each console keeps one address; RomM works the same way, one server per console with several accounts on it. On a family console each person has their own friends and a child sees only who was set up for them, and friends on the server mean nothing has to be kept in step between consoles. With only the owner making friends, players never add anyone, a child cannot add a stranger and nobody appears by accident. LinkUp is only for people you know, so a name is enough. A console that is removed knows who gave it the way on, and a friend leaving a list needs no announcement. The costs: the admin page does more, and an account has to sign in on the console once before it can be picked.
- **Numbers:** #654, "LinkUp: play a game with a friend on another CabinetOS console over the internet"; PR #666, "LinkUp: the console's side, step 3 of #654".
- **Replaces:** the earlier plan of a person joining more than one server, with a friends list of their own on each.
