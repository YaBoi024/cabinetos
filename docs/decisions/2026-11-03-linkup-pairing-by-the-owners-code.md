# A LinkUp console pairs with a code the owner makes, and the code never travels

- **Decided:** On the admin page the owner picks whose friend it is for and gets the server's address and a code of 12 characters in 3 groups, with no look-alike letters, to send in a message. The person types both on their console. A code works once, expires after 7 days, and attempts at one are rate limited. The code itself never travels: each side sends only a slow-hash proof of it, and afterwards the console remembers the server's key, so retyping a changed address needs no new pairing. A console's key is made the first time LinkUp is turned on, not at first boot.
- **Date:** 2026-11-03
- **Why:** One message and it is done, with no back-and-forth, and the owner need not be around when the person sets up. The public port can ignore anyone without a valid code, so it holds nothing for strangers. A proof and not the code, so that someone sitting between a console and its server cannot pose as either, even on a plain IP with no certificate, which most home owners will have; an independent review found the proof sound, and a PAKE would add a second protocol for a margin nothing here spends. The key waits for first use because the console connects only to fixed places, and to the optional ones only when the player uses them. The cost: a code can be passed on and whoever uses it first takes the place, so it works once, and the owner sees the username on the People list and can remove them.
