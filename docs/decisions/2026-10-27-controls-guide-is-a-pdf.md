# The printable controls guide is a PDF

- **Decided:** the one-page controls guide is a PDF in the wiki folder, `docs/wiki/controls.pdf`, made from `docs/wiki/controls.html` beside it and linked from the wiki's Buttons and shortcuts page. Nothing about it is on the console.
- **Date:** 2026-10-27
- **Why:** a PDF prints the same on every printer: one page, in colour. A printable wiki page would depend on the browser's margins and paper, and browsers leave background colours off when printing unless the person turns them on. The HTML source keeps the PDF easy to change and makes it readable in a diff.
- **Numbers:** #597 (The one-page controls guide, as a PDF on the wiki).
- **Replaces:** none.
