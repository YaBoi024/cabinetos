# One sound rule on every PC, read from what each output reports

- **Decided:** The screen the picture is on plays the sound. An output takes over only if it reports something actually plugged in. Nothing else takes the sound. When the screen's sound is gone (asleep, off, unplugged) the result is silence, never a speaker in the PC. There is no setting. One WirePlumber script holds this on every PC by reading what each output reports, never its name (`system_files/usr/share/wireplumber/scripts/cabinetos-sound-output.lua`), and the image build stops, saying what to redo, if a WirePlumber update changes what it stands on (`build_files/sound-output-rule.sh`). The rule starts once a screen's sound has been seen connected and stays on for WirePlumber's run, so a PC with no screen sound keeps its speakers or its jack. USB outputs rank below the screen and no chosen output is remembered. Remote Play's or Steam's own choice wins while it stands.
- **Date:** 2026-11-04. The rule is MMagTech's, 2026-10-13 and 2026-10-21 and 22.
- **Why:** One rule, because the rule was general and each fix was for one kind of hardware: a priority for USB sound, then a file edit for a built-in speaker on the usual profile. Each new PC brought a new report, because an output with no way to sense a plug can be wired many ways and every one of them outranked the screen. The aim is that it just works; the upkeep is held to a build that fails and says so, and never narrows the fix.
  Silence and not the speaker, because a console is designed around a TV, every modern TV has speakers, a monitor without them has a jack, and Remote Play carries the sound through its own output. The screen's sleep removes its output, so falling back would move the sound to the speaker at every sleep.
  No menu, because picking an output would turn the headphone switching off, its "Automatic" would still need this rule, and #341 said no setting.
  It waits for a screen because, with the rule on from the first moment, a laptop or a desktop whose screen has no sound would have no way to play at all. The cost: on a PC with a speaker or a jack that cannot sense a plug, a console started with the TV off plays there until the TV first comes on.
- **Numbers:** #655, "Sound: a line-out jack that cannot sense a plug takes the sound from the screen (Beelink SER, UCM profile)"; #550, "Sound: a built-in speaker never takes the sound from the TV"; #547, "Sounds plays only from onboard speakers (Beelink ser9)"; #341, "No audio [Expected on this machine]".
