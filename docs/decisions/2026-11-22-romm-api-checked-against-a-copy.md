# The client is held to a copy of RomM's published API

- **Decided:** What the console's RomM client sends and reads is a list in the repository, checked on every pull request against a copy of RomM's own description of its API, kept in the repository and cut to the calls the client makes. The copy is of the release the console is tested against, made by RomM's own tool in RomM's published image. Once a month, and on a pull request that changes the RomM version needed, the same list is checked against RomM's newest release of that version. It checks names and kinds, never what RomM does with them.
- **Date:** 2026-11-22
- **Why:** RomM changes its API in its own releases, and nothing told the console but a screen that broke. The list is checked against the code too, so it cannot fall behind. The copy makes the check offline and takes seconds on every pull request, and its diff when a release moves is what RomM changed in what the client uses. RomM's own tool in its own image gives the same document a running server does and needs no server of ours; checked on 2026-11-22, with 5.5.0-beta.1. The copy is 277 KB, the calls the client makes out of 290; RomM's whole description is 993 KB. Not taken: the description read from a running server, which needs the project's test server to be reachable from GitHub; the description made on each pull request, which pulls a 930 MB image every time; and no check, leaving a renamed field to be found on a television.

- **Replaces:** none.
