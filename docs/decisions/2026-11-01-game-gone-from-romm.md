# A game RomM no longer has leaves the console

- **Decided:** A game deleted in RomM leaves the console at the next start with the server there: a played copy or a download, with its saves, states and screenshots, on every system. Nothing happens while the server is away.
- **Date:** 2026-11-01
- **Why:** RomM deletes a game's saves, states and screenshots along with the game, so anything the console kept for it could never be sent anywhere. Deleting a game in RomM is how a library is managed, and the console follows RomM (decision "The console uses RomM, never manages it"). A download kept after its game is gone can't be played from the Library. When RomM gives the same game a new entry, the console sees that entry as not downloaded anyway, so keeping the old copy saves no download.
- **Numbers:** #625 (Games deleted in RomM stay on the console: their pictures download again at every start, and an offline save never reaches RomM), #636 (A game deleted in RomM leaves the console at the next start).
- **Replaces:** none.
