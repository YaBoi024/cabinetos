# Screenshots

Take a picture of the game you are playing:

- **Screenshot** in the [pause menu](pause-menu.md). The picture is the game
  alone, without the menu.
- With [In-game shortcuts](navigation.md#in-game-shortcuts) on: hold the
  shortcut button and press the **left face button** (X on Xbox, Square on
  PlayStation, Y on Nintendo). This works with the pause menu open too.

*Screenshot saved* means it worked. The picture is saved on the console, then
sent to **your own gallery in RomM** for that game (the console sends it again
later if the server is away). There is no gallery on the console itself: look
at them in RomM, or copy them off with [File access](file-access.md).

The shortcut works in the built-in emulators. In the separate ones (Switch,
PS3, Xbox, Xbox 360, Wii U, PS Vita, Model 2 and Model 3), use the pause menu.
